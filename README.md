# Legacy Exterior Services LLC

A high-converting, mobile-first business website and lead generation platform built for exterior property care and wood restoration services.

##  Key Features

- **Mobile-First Architecture:** Fully responsive layout optimized for smartphone users searching on the go, featuring a sticky mobile bottom call bar for instant conversions.
- **Conversion-Optimized Design:** Strategic visual hierarchy utilizing deep slate navy authority containers and rich amber-gold call-to-action touchpoints.
- **Interactive Sub-Pages:** Dedicated deep-dive service pages and an About Us section with built-in navigation anchors and frictionless lead capture forms.
- **Visual Portfolios:** Side-by-side before-and-after project transformation galleries to build immediate local trust.

## 🛠️ Tech Stack

- **Framework:** React / Vite
- **Styling:** Tailwind CSS
- **Hosting & Deployment:** Vercel

## 🚀 Local Development

To run this project locally for development or customization:

```bash
# Clone the repository
git clone [https://github.com/your-username/legacy-exterior-services.git](https://github.com/your-username/legacy-exterior-services.git)

# Navigate to the project directory
cd legacy-exterior-services

# Install dependencies
npm install

# Run the development server
npm run dev
